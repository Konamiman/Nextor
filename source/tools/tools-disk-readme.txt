This disk contains NEXTOR.SYS and the Nextor command line tools.

If a COMMAND3.COM file is present too, the disk can be used to
boot straight to the DOS prompt on a computer with a Nextor
kernel ROM.

NEXTORJ.SYS is the variant of NEXTOR.SYS with Japanese messages;
to use it, delete NEXTOR.SYS and rename NEXTORJ.SYS to
NEXTOR.SYS.

COMMAND3.COM displays its messages in Japanese when the kanji
mode is active (unless the ERRLANG environment item is set to
EN).

Run any tool without arguments to get usage information (except
XDIR, which lists the current directory; use TYPE XDIR.COM). The
files in the HELP directory can be browsed with the HELP command.
See the Nextor User Manual for the details.

Nextor documentation, source code and binaries:
https://github.com/Konamiman/Nextor
