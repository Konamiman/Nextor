# BOOT

_Versions: 2.44_

## Format

```
BOOT d:
```

## Purpose

Assigns a new Nextor boot drive.

## Use

Simply changes the drive used to reboot Nextor from BASIC.

## Examples

```
BOOT B:
```

Nextor will attempt to reboot from drive `B:` or will be redirected to the default drive.
