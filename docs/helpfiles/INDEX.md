# Help index

The following standard commands are available. For more information on a specific command, type:

```
HELP  command name
```

| Command | Description |
|---|---|
| [`ALIAS`](ALIAS.md) | displays/sets aliases |
| [`ASSIGN`](ASSIGN.md) | logical to physical drive assignment |
| [`ATDIR`](ATDIR.md) | changes the attributes of directories |
| [`ATTRIB`](ATTRIB.md) | changes the attributes of files |
| [`BASIC`](BASIC.md) | goes into MSX disk BASIC |
| [`BEEP`](BEEP.md) | makes beeping sound |
| [`BOOT`](BOOT.md) | assigns a new Nextor boot drive |
| [`BUFFERS`](BUFFERS.md) | displays/sets the number of disk buffers |
| [`CD`](CD.md) | see [`CHDIR`](CHDIR.md) |
| [`CDD`](CDD.md) | displays/sets the current directory and drive |
| [`CDPATH`](CDPATH.md) | displays/sets the directory search path |
| [`CHDIR`](CHDIR.md) | displays/sets the current directory |
| [`CHKDSK`](CHKDSK.md) | checks the integrity of a disk |
| [`CLS`](CLS.md) | clears the screen |
| [`COLOR`](COLOR.md) | changes screen colors |
| [`CONCAT`](CONCAT.md) | joins files together |
| [`COPY`](COPY.md) | copies files |
| [`CPU`](CPU.md) | displays/sets the CPU mode |
| [`DATE`](DATE.md) | displays/sets the current date |

| [`IF`](IF.md) | executes command if equation is true |
| [`IFF`](IFF.md) | sets Command Mode ON if equation is true |
| [`INKEY`](INKEY.md) | reads character into environment item |
